Tema 1

      
Não existe tarefasFiltradas. De propósito.

      
Se o estado guardasse tarefas e também tarefasFiltradas, existiriam duas fontes de verdade. Basta um filtro mudar e alguém esquecer de recalcular a segunda lista para a tela mostrar uma coisa e o estado dizer outra.

      
Quando a lista é derivada a cada ciclo por derivarVisiveis(estado), ela é uma função dos critérios atuais: não tem como ficar desatualizada, porque ela nem é guardada. O teste 3 do enunciado (“Limpar filtros”) existe para pegar exatamente isso: se só a tela ou só os controles voltam, há duas fontes de verdade.

    

    
export const estado = {
  tarefas: [],             // como veio de carregarTarefas(). NUNCA reordenado
  busca: '',
  status: 'todos',
  prioridade: 'todas',
  ordenacao: 'original',
  carregamento: 'inicial', // 'carregando' | 'sucesso' | 'erro'
  erro: null
};

// Recebe o estado, devolve a lista visível. PURA: não toca o DOM,
// não altera o estado. Chamada UMA vez por renderização.
export function derivarVisiveis(estado) {
  let visiveis = estado.tarefas.filter(t =>
    bateBusca(t) && bateStatus(t) && batePrioridade(t));
  if (estado.ordenacao !== 'original')
    visiveis = [...visiveis].sort(porPrazo);
  return visiveis;
}

Tema 3

      
Cada ouvinte faz duas coisas. Só duas.

      
Escreve no estado e chama atualizar(). Nenhum ouvinte filtra lista, esconde cartão, lê outro controle ou toca o DOM. Por isso a ordem em que você mexe nos controles não importa (teste 2): o resultado depende só do valor atual do estado.

      
E por isso “Limpar filtros” é type="button", não reset: reset limparia só os controles e o estado ficaria com os filtros antigos. O botão restaura o estado; renderizar() restaura os controles a partir dele.

    

    
evento (input / change / click)
  → ouvinte escreve no estado             (js/main.js)
  → atualizar() = renderizar(estado)      (js/tela.js) — o ÚNICO ponto
       1. visiveis = derivarVisiveis(estado)   (js/estado.js)
       2. renderizarTarefas(visiveis)          (replaceChildren)
       3. contagem "N de M" + mensagem #status
       4. controles sincronizados a partir do estado

// js/main.js
campoBusca.addEventListener('input', (e) => {
  estado.busca = e.target.value;   // 1. escreve no estado
  atualizar();                     // 2. chama o mesmo ponto
});
botaoLimpar.addEventListener('click', () => {
  Object.assign(estado, criterioInicial());
  atualizar();
